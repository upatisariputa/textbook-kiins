# SPEC — "I Dress Up" interactive courseware sample (pitch demo)

## 0. Context
- Pitch demo for a Korean ed-tech client. Audience: Korean kids, grades K-2, learning English.
- Textbook: Scholastic *First Comprehension: Comics*, unit "I Dress Up", book pages 6 (4-panel comic) and 7 (worksheet).
- Reference player screenshot: `source/reference_player_p16.png` (left = e-book page, right = sentence list, dark green top/bottom bars, mint left background). Keep that look & feel, but change layout and tabs as below.
- It is a **demo that must actually work** in a browser. No fake/mock features: anything shown must really function.

## 1. Tech constraints
- Plain HTML + CSS + vanilla JavaScript (ES modules). **No build step, no npm, no frameworks, no CDN, no external fonts, no network calls.** Must work offline.
- Run: `python3 -m http.server 8000` in project root → `http://localhost:8000/`.
- Targets: landscape tablet 1280×800 (primary) and desktop Chrome/Safari ≥ 1024px wide. Use Pointer Events (touch + mouse). Touch targets ≥ 48px.
- Fonts: `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. Rounded, friendly, large.
- Suggested layout:
  ```
  index.html
  css/app.css
  js/main.js            (app shell, tab router)
  js/audio.js           (AudioPlayer service)
  js/ebook.js           (left pane: page image + hotspot highlight)
  js/tabs/words.js, sentences.js, shadow-reading.js, shadow-writing.js, quiz.js
  js/ui/*.js            (shared widgets: handwriting canvas, draw canvas, effects/confetti, etc.)
  data/content.js       (ALL content + tunable config in one place)
  assets/img/           (copied from source/)
  assets/audio/         (generated by scripts/gen-audio.sh)
  scripts/audio-manifest.tsv, scripts/gen-audio.sh
  README.md
  ```
- Put every tunable in `data/content.js` `CONFIG`: pane ratio, blink count/duration, click cycle order, shadow pause factor, accepted answers, voice mapping, choice lists.

## 2. Global rules (from the client)
1. **Korean is audio-only. Never display Korean translation text on screen.**
   - Single exception: WORDS meaning-choice buttons show Korean words (광대/공룡/벌/분장하다). Keep this exception isolated & documented.
   - UI chrome uses icons + short English labels (e.g., "Listen", "Done", "Next", "Retry"). No Korean UI strings.
2. Layout: **left e-book pane small (35%), right practice pane wide (65%)**.
3. **Sync highlight**: whatever item is active on the right, the matching region of the textbook page on the left blinks (see §4).
4. Bottom bar has exactly 5 tabs: `WORDS`, `SENTENCES`, `SHADOW READING!`, `SHADOW WRITING!`, `QUIZ`.

## 3. App shell
- Top bar (dark green like reference): back chevron (no-op), centered title `First Comprehension Comics_I Dress Up`.
- Body: left pane 35% (mint background) / right pane 65% (white).
- Bottom bar (dark green): 5 tabs with simple inline-SVG icons + labels; active tab clearly highlighted.
- Switching tab: stop any audio/recording, clear highlights, reset that tab's transient state is NOT required (keep progress while switching is fine).
- Respect `prefers-reduced-motion` (no blinking/shaking; use steady highlight).

## 4. Left pane — e-book with highlight
- Shows ONE page image at a time: `page6.png` or `page7.png` (1810×2346 px), `object-fit: contain`, centered. Small toggle `p.6 | p.7` at the top of the pane for manual switching.
- Overlay layer exactly matching the rendered image box; regions come from `source/hotspots.json` (values are **percent** of the page image: left/top/width/height). Copy the data into `data/content.js` or fetch the JSON.
- `highlight(page, regionId)`: auto-switch page if needed → overlay box with translucent yellow fill `rgba(255,214,0,.35)` + 3px orange border, **blinks 3 times (~1.2s)**, then stays as steady outline while the item is active. Only one region active at a time. `clear()` removes it.
- Mapping:
  | Right side item | Page | Region |
  |---|---|---|
  | WORDS clown / dinosaur / bee | 6 | panel1 / panel2 / panel3 |
  | WORDS dress up | 6 | title |
  | SENTENCES & SHADOW READING: title / s1..s4 | 6 | title / panel1..panel4 |
  | SHADOW WRITING: WRITE 1 / WRITE 2 | 7 | write1 / write2 |
  | SHADOW WRITING: SHADE 1 / SHADE 2 | 7 | shade1 / shade2 |
  | SHADOW WRITING: DRAW | 7 | draw |
  | QUIZ part 1 item clown/dinosaur/bee/me | 6 | panel1..panel4 |
  | QUIZ part 2 photo | 7 | (no region, just show page 7) |

## 5. Audio
- `AudioPlayer`: `play(id) → Promise` (resolves on end), `sequence(ids, gapMs=250)`, `stop()`. Starting new playback stops the previous one. Expose `isPlaying` / events for UI states.
- Files: `assets/audio/<id>.m4a`. If a file fails to load/play, **fall back to `speechSynthesis`** using the text/lang/pitch/rate from the manifest data, so the app works before audio is generated. (Fallback must be automatic and silent.)
- `scripts/audio-manifest.tsv` columns: `id<TAB>voice<TAB>rate<TAB>text`. `scripts/gen-audio.sh` reads it and runs macOS `say -v <voice> -r <rate> -o tmp.aiff "<text>"` then `afconvert -f m4af -d aac tmp.aiff assets/audio/<id>.m4a`. Idempotent, prints progress, skips existing unless `--force`. **You do not need to run it** (your sandbox may block `say`); the reviewer will run it.
- Voices (placeholders until professional TTS/voice actors):
  - English narrator: `Samantha`, rate 140.
  - Korean: `Yuna`, rate 180.
  - SHADOW READING: all sentences use the narrator voice `Samantha` rate 140 (CHANGE_04: character voices removed — `Jester` was mostly laughter).
  - No sound effects (CHANGE_04: WebAudio ding/boop/sparkle removed). Spoken praise stays: `praise_great` "Great job!", `praise_try` "Try again!".
- Audio needed (define all in the manifest; ids are suggestions):
  - Words EN: `w_clown`, `w_dinosaur`, `w_bee`, `w_dressup` ("dress up"). Words KO: `w_clown_ko` 광대, `w_dinosaur_ko` 공룡, `w_bee_ko` 벌, `w_dressup_ko` 분장하다.
  - Sentence full EN (narrator), sentence KO, chunk EN for each chunk, character-voice full sentence for shadow reading (`sr_*`).
  - Worksheet questions EN + KO, model answers EN + chunk EN.

## 7. Tabs

### 7.1 WORDS
- 4 cards in one row (face-down: colorful back with "?" pattern).
- **One tap = play EN word audio + 3D flip** to front (image + English word). Tapping a flipped card replays the EN audio. Highlight left region.
- Under each card: 2 meaning choices (Korean text; the correct one + one random other meaning; random order). Choices disabled until the card is flipped.
- Correct → green border + ✓ badge + ding + play KO audio of the word. Card done.
- Wrong → card turns orange + shake + boop + replay EN word; the wrong choice gets disabled; child retries.
- All 4 done → celebration (confetti + "Great job!") and a `Next ›` button to SENTENCES.

### 7.2 SENTENCES
- Top: **tile stage** showing the active sentence as 3 tiles side by side (title has 2). Each tile = image + chunk text under it.
- Below: list of 5 sentence rows (title + s1..s4), English only, chunks visually separated (e.g., subtle `/` or spacing). Each row shows a small pill indicating the next playback language: `EN` or `KO`.
- Tap a row → becomes active, left highlight, then plays by **click cycle EN → KO → EN → …** (per row):
  - EN: play chunk audios in sequence; the matching tile lights up (others dimmed) and the chunk text in the row gets a karaoke highlight.
  - KO: play KO audio of the sentence; all tiles lit; pill shows a speaker animation. **No Korean text.**
- Replaying = tapping the row again (continues the cycle).

### 7.3 SHADOW READING!
- One sentence at a time (title + s1..s4) in a large card with the panel image (`crops/p6_panelN.png` for s1..s4; for title use `crops/dressup.png`) and the sentence.
- Flow per sentence: play **character voice** (`sr_*`) with the sentence highlighted → **"Your turn!" pause** with pulsing mic icon and countdown ring for `max(2.5s, audioDuration × 1.8)` (factor in CONFIG) → auto-advance to the next sentence. Controls: Play/Pause, Prev, Next, Repeat.
- **Record my voice** toggle (off by default): when on, record the mic during each pause window with MediaRecorder; afterwards each sentence shows `▶ Original` and `▶ Me` buttons to compare. Local only, nothing uploaded.
- **Reading video** button: opens a panel with live camera preview (getUserMedia video+audio) and the 5 sentences shown big with karaoke highlight driven by the same character audio; Start/Stop recording; after stop show playback + `Save video` (download blob). Local only.
- Permission denied/unsupported → friendly inline message with icon; the rest keeps working.
- No pronunciation scoring.

### 7.4 SHADOW WRITING!
- Stepper at top: `WRITE 1`, `WRITE 2`, `SHADE 1`, `SHADE 2`, `DRAW`. Selecting a step highlights its left region.
- Question/statement row has a 🔊 button using the same **EN → KO** click cycle as SENTENCES (KO audio only).
- **WRITE n**:
  - After the question audio, the model answer appears as 3 chunk boxes that **blink one after another in turn** (chunk1 → chunk2 → chunk3, 2 loops; chunk EN audio may play with each).
  - Writing area with two modes (toggle):
    1. **Handwriting (default)**: canvas with English 4-line guide; faint trace text of the model answer (toggle "Trace" on/off); pen, eraser, clear; pressure-free smooth strokes; works with finger/stylus/mouse. `Done` → praise effect and shows the model answer under the canvas. (No handwriting recognition.)
    2. **Keyboard**: text input + `Check` → **rule-based auto-correction (real, not mocked)**: pick the closest accepted answer (word-level edit distance, case/punctuation-insensitive), then show a corrected line "red-pen style": wrong/misspelled words struck through with the correct word above, missing words inserted with a caret, extra words struck, missing capital letter at start and missing final period flagged. All correct → celebration. Show a short English summary like "2 fixes". Handle empty input.
- **SHADE n**: statement + big dotted TRUE / FALSE circles like the worksheet. Tap → crayon-like shading animation fills the circle (scribble texture, gray like the answer key). Correct → ding + green ✓; wrong → boop + shake, shading fades, retry.
- **DRAW**: question + drawing canvas (6 colors, 2 brush sizes, eraser, clear, `Save` PNG download).

### 7.5 QUIZ
- **Part 1 – Look and complete** (4 items: clown, dinosaur, bee, me):
  - Panel image + sentence `I dress up ______` + 3 chunk choices (e.g., "as a clown." / "as a bee." / "as me!"). Correct choice + 2 random others.
  - Correct → blank filled, full sentence EN audio, ding, next. Wrong → shake, boop, choice disabled, retry. Progress dots; final score "4/4" + confetti.
- **Part 2 – Upload my book**:
  - `Take a photo` button → `<input type="file" accept="image/*" capture="environment">` (camera on tablets, file picker on desktop).
  - Show photo preview, then a **big red hand-drawn circle (동그라미) stamp animation** drawn over the photo (SVG stroke animation), confetti, "Great job!" audio. `Retake` button. Local only, no upload, no grading.

## 8. Visual style
- Colors close to reference: bars `#0f6b5c`-ish dark green, accent teal, left pane mint `#dff3ec`, highlight yellow/orange, correct green, wrong orange.
- Kid friendly: rounded 16px corners, soft shadows, bouncy but short animations (≤ 600ms) except intentional blinks.
- Must fit 1280×800 without page scroll (internal scroll in right pane is OK).

## 9. Acceptance checklist (the reviewer will test these in a real browser)
1. Loads with no console errors at 1280×800; 35/65 split; 5 tabs labeled exactly as in §2.
2. No Korean translation text visible anywhere except WORDS choice buttons.
3. Every interactive item highlights the correct left region (table §4), with page auto-switch and 3 blinks.
4. Audio works from files when present and falls back to speechSynthesis when missing.
5. WORDS: tap→audio+flip; correct/wrong behaviors; completion celebration.
6. SENTENCES: chunk-synced tiles + karaoke; EN→KO cycle with pill indicator.
7. SHADOW READING: character voice → timed pause → auto-advance; record/compare works (when mic allowed); reading video record/playback/save works (when camera allowed); graceful denial.
8. SHADOW WRITING: chunk blink sequence; handwriting canvas with trace; keyboard auto-correction gives correct red-pen output for e.g. "the girl dress up as clown" (fixes: capital T, dresses, missing "a", missing period); SHADE answers FALSE/TRUE; DRAW canvas & save.
9. QUIZ: 4 completion items with scoring; photo → preview → circle stamp + confetti.
10. `scripts/gen-audio.sh` generates every id referenced by the app (manifest covers all ids used in `data/content.js`).
11. README.md: how to run, how to regenerate audio, where to edit content/config.
